# Proposal

## Why

`apps/web` is currently a stock Next.js bootstrap stub (`web-bootstrap` spec)
with no real screens, while the two apps that actually exist — the borrower
channel and the staff channel — live under the non-obvious names
`apps/borrower-web` and `apps/staff-web`. ADR-0002 originally planned
`apps/web`, `apps/admin`, and `apps/backoffice`; ADR-0003 built
`apps/borrower-web` and `apps/staff-web` instead and left the `apps/web` stub
in place "for now." `apps/admin` was never built — the tenant administrator
role lives inside the staff app. The result is a confusing split: three
web app folders, one of them unused, none matching the original naming
intent. This change collapses that down to the two folder names the kit
always intended: `apps/web` (borrower) and `apps/backoffice` (staff).

## What Changes

- Delete `apps/web` (the unused stock bootstrap stub).
- Rename `apps/borrower-web` → `apps/web`. This becomes the borrower-facing
  app.
- Rename `apps/staff-web` → `apps/backoffice`. This becomes the staff
  console app, including the tenant administrator screens it already
  contains.
- **BREAKING**: package names change — workspace package `web` (the deleted
  stub) is removed; `borrower-web` is renamed to `web`; `staff-web` is
  renamed to `backoffice`. Any `@aim-ready/*`-style internal import or script
  that references the old package names must be updated in the same change.
- Update every reference to the old paths/names: `package.json` "name"
  fields, `pnpm-workspace.yaml` (if paths are listed explicitly),
  `turbo.json`, `.github/workflows/ci.yml`, `AGENTS.md`'s "Where things live"
  section, `openspec/config.yaml`'s context stack line.
- Add `docs/adr/0004-...md` superseding ADR-0002 (which still names the
  never-built `apps/admin`/`apps/backoffice` plan) and ADR-0003 (which
  created the `borrower-web`/`staff-web` names), recording the final
  `web`/`backoffice` naming.
- No application behavior, routes, RBAC, or screens change — this is a
  rename plus reference cleanup, not a feature change.

## Capabilities

### New Capabilities

(none)

### Modified Capabilities

- `web-bootstrap`: the capability described a stock bootstrap stub at a
  standalone `apps/web` that no longer exists after this change — `apps/web`
  is now the borrower app, already specified by `borrower-portal`. The
  generic "renders a default App Router shell" requirement is removed, and
  the shared-UI-components requirement is updated to name the two web apps
  that actually exist (`apps/web`, `apps/backoffice`) instead of the planned
  three (`apps/web`, `apps/admin`, `apps/backoffice`).

## Impact

- **Filesystem**: `apps/web` deleted; `apps/borrower-web` → `apps/web`;
  `apps/staff-web` → `apps/backoffice`. Git history preserved via `git mv`.
- **Config/tooling**: `package.json` names in all three affected app
  directories, `pnpm-workspace.yaml`, `turbo.json`, `.github/workflows/ci.yml`,
  any `tsconfig` path references, lockfile (`pnpm-lock.yaml` regenerated by
  `pnpm install` after the rename).
- **Docs**: `AGENTS.md`, `openspec/config.yaml` context, new ADR-0004
  superseding ADR-0002 and ADR-0003.
- **Specs**: `web-bootstrap` delta (see above). `borrower-portal`,
  `staff-console`, and `ui-kit` specs already describe apps generically (“the
  borrower portal”, “the staff console”) with no hardcoded folder paths, so
  they need no delta.
- **Roles**: no RBAC or role-visibility change. All 9 roles keep the same
  screens; only the folder/package name that hosts the staff console changes.
- **No schema, API contract, credit-policy, decisioning, external-adapter,
  or maker-checker behavior changes.** Both apps remain mock-data-only
  prototypes per ADR-0003; this is a structural rename, not a functional
  change.
